2. JA3 ve JA4 Parmak İzi Nedir?

Cloudflare, Google ve Akamai gibi devler, gelen her HTTPS isteğinin Client Hello paketindeki 5 temel parametreyi virgülle birleştirip MD5 hash'ini çıkarır. Bu hash'e JA3 (veya yeni nesil JA4) denir:

  1. TLS Versiyonu (Örn: `771` -> TLS 1.2, `772` -> TLS 1.3).
  2. Desteklenen Şifre Süitleri (Cipher Suites listesi).
  3. Uzantı Listesi (Extensions listesi).
  4. Eliptik Eğri Algoritmaları (Elliptic Curves).
  5. Eliptik Eğri Nokta Formatları (Point Formats).

Eğer sizin HTTP başlığınızda "Ben Windows 11 Chrome'um" yazıyor ama JA3 hash'iniz Python OpenSSL çıkıyorsa; anti-bot sistemi 1 milisaniye içinde bağlantıyı koparır veya 403 Forbidden döner.

4. Çözüm: `curl_cffi` ve Go `tls-client` ile Tam Taklit

Çerez çiftliğimizde çerezleri hızlıca toplamak için ağır Playwright yerine hafif HTTP istekleri kullanacağımız zaman, standart `requests` yerine BoringSSL motoru kullanan özel kütüphaneler devreye girer:

🚀 Python Çözümü: curl_cffi ile Chrome 120/130 İmpersonation
from curl_cffi import requests

# impersonate="chrome124" veya "chrome130" parametresi:
# 1. TLS Handshake paketini Chrome ile bit'i bit'ine aynı yapar.
# 2. HTTP/2 SETTINGS çerçevelerini Chrome standartlarında gönderir.
# 3. JA3 ve JA4 hash'i gerçek Chrome ile %100 eşleşir!

session = requests.Session(impersonate="chrome124")
response = session.get(
    "https://www.google.com/search?q=hitbot+test",
    proxies={"https": "http://user:pass@proxy:port"}
)

print("Durum Kodu:", response.status_code) # 200 OK!
print("Gelen Çerezler:", session.cookies.get_dict())
