3. Otomatik ZIP Paketleme Pipeline'ı (`packager.py`)

Satışa hazır her 500 veya 1.000 profili tek tıkla şık bir ZIP dosyasına dönüştüren, içine kullanım kılavuzu ve doğrulama sertifikası koyan Python kodu: 

import os
import zipfile
import json
from datetime import datetime

def package_cookie_batch(batch_id: str, profiles_dir: str, output_zip_path: str):
    """500 adetlik çerez profilini müşteri için ZIP paketine dönüştürür."""
    readme_content = f"""===================================================================
ORGANIK ISITILMIS COKIE PAKETI - KALITE GUVENCE SERTIFIKASI
Paket ID: {batch_id}
Uretim Tarihi: {datetime.utcnow().strftime('%Y-%m-%d %H:%M:%S')} UTC
Hedef Ulke: Turkiye (TR) | Dil: tr-TR
Uyumluluk: Dolphin{{anty}}, AdsPower, GoLogin, Playwright, BAS
===================================================================
KULLANIM TALIMATI:
1. 'cookies_json/' klasoru icindeki her dosya 1 adet bagimsiz profildir.
2. Her dosya icin yanindaki 'meta.json' User-Agent degerini kullaniniz.
3. Dolphin{{anty}} kullaniyorsaniz 'dolphin_bulk_import.json' dosyasini 
   dogrudan Import sekmesine surukleyip birakabilirsiniz.
===================================================================
"""
    with zipfile.ZipFile(output_zip_path, 'w', zipfile.ZIP_DEFLATED) as zipf:
        # 1. README / Garanti Belgesi ekle
        zipf.writestr("README_KURULUM.txt", readme_content)
        
        # 2. Profilleri ekle
        for root, _, files in os.walk(profiles_dir):
            for file in files:
                file_path = os.path.join(root, file)
                arcname = os.path.relpath(file_path, profiles_dir)
                zipf.write(file_path, arcname)

    print(f"Paketleme Tamamlandi: {output_zip_path}")
PYTHON 3.12 / PACKAGER
