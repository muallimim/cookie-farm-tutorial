Modül 11: Proxy Stratejileri 1: Kotalı Residential vs. Sabit ISP

GB başına faturalandırılan konut proxy'lerinin maliyet tuzağı, sınırsız bant genişlikli sabit port ISP proxy mimarisi ve ASN güven skorları.

1. Kotalı Proxy Tuzağı: Matematik Neden Yalan Söylemez?

Piyasada BrightData, Oxylabs, Smartproxy veya yerel sağlayıcılar (Sağlam Proxy vb.) residential (konut) proxy satarken GB başına ücret alır.

💸 Çerez Ticaretinde Kotalı Proxy İflas Hesabı
  • 1 GB Konut Proxy Fiyatı: 3.00$ (Dolar 50 TL iken = 150 TL).
  • Medya engellemesi olmadan 1 profilin 8 siteyi gezmesi: ~25 MB.
  • 1 GB (1.024 MB) kotadan kaç profil çıkar? -> 1024 / 25 = 40 profil.
  • Profil Başına Sadece Proxy Maliyeti: 150 TL / 40 = 3.75 TL!

Eğer bir profili üretmek size 3.75 TL'ye mal oluyorsa, piyasada 0.50 TL (1 Cent) fiyata toptan çerez satamazsınız! Kotalı proxy ile bu işi yapmaya kalkan herkes zarar eder ve sistemi kapatır.

2. Çözüm: Sınırsız Bant Genişlikli (Unlimited Bandwidth) ISP Proxy'ler

Piyasada GB başına değil, sabit port başına aylık kiralama yapan kurumsal sağlayıcılar vardır (Örn. IPRoyal, Rayobyte, Webshare, Proxy-Seller).

⚖️ KOTALI RESIDENTIAL VS. SINIRSIZ ISP PROXY MODELİ
[KOTALI MODEL]: 1 GB Kullanırsın ──> 150 TL Ödersin 10 GB Kullanırsın ──> 1.500 TL Ödersin 100 GB Kullanırsın ──> 15.000 TL Ödersin! (Batış Garantili!) ════════════════════════════════════════════════════════════════ [SINIRSIZ ISP PORT MODELİ]: 10 Port Kirala ──> Aylık Sabit: 25$ (1.250 TL) 100 GB Tüket ──> Aylık Sabit: 1.250 TL (Ek ücret YOK!) 1.000 GB Tüket ──> Aylık Sabit: 1.250 TL (Ek ücret YOK!) Sonuç: 50.000 profilde maliyet profil başı 0.02 TL'ye düşer!

3. ASN İtibarı: Datacenter vs. ISP vs. Residential

Google ve Cloudflare, bağlanan her IP adresinin ASN (Autonomous System Number) kaydını sorgular (MaxMind / IPinfo veritabanları):

IP Sınıfı Örnek Sağlayıcı Google Güven Skoru Çerez Çiftliğinde Kullanım Alanı
Datacenter (Sunucu IP) Hetzner, OVH, DigitalOcean Çok Düşük (0.1 - 0.3) Doğrudan Google'a gidilmez! Yalnızca ara siteleri (Vikipedi, haberler) hızlıca taramak için kullanılır.
Static ISP (Sabit Hat) Turknet, Superonline Statik Yüksek (0.7 - 0.85) Sınırsız port kiralayarak 7/24 kesintisiz profil üretmek için idealdir.
Residential (Ev İnterneti) Türk Telekom ADSL/Fiber Çok Yüksek (0.85 - 0.95) Kotalıysa sadece medya filtresiyle kullanılır.
Mobile 4G/5G (Hücresel) Turkcell, Vodafone 4G Kusursuz (0.95 - 1.0) Dünyanın en güvenilir IP sınıfıdır. Asla CAPTCHA patlamaz!

4. Proxy Sağlık Kontrolü (Health-Check Daemon)

Çerez çiftliğiniz çalışırken ölü veya düşmüş bir proxy yüzünden worker'ların takılmaması için arka planda çalışan Python sağlık kontrolcüsü: 

import asyncio
import httpx
import time

async def check_proxy_health(proxy_url: str) -> dict:
    """Proxy'nin çalışıp çalışmadığını, IP'sini ve gecikme süresini test eder."""
    start = time.time()
    try:
        async with httpx.AsyncClient(proxies=proxy_url, timeout=5.0) as client:
            resp = await client.get("https://api.ipify.org?format=json")
            latency_ms = int((time.time() - start) * 1000)
            if resp.status_code == 200:
                ip = resp.json().get("ip")
                return {"healthy": True, "ip": ip, "latency_ms": latency_ms}
    except Exception as e:
        return {"healthy": False, "error": str(e), "latency_ms": None}

    return {"healthy": False, "error": "Unknown", "latency_ms": None}
