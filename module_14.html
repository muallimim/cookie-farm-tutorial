Modül 14: Ağ Trafiği Optimizasyonu (Kotayı %90 Düşüren Medya Filtreleme)

Bir web sayfasının veri tüketim röntgeni, Playwright page.route müdahalesiyle resim/video/font engelleme ve çerez kaybı yaşamadan kotayı %90 düşürme formülü.

1. Trafik Nereye Gidiyor? 25 MB'lık Sayfanın Röntgeni

Bir haber sitesine (örneğin Hürriyet veya Sözcü) girdiğinizde, tarayıcınız ortalama 20 ila 35 MB veri indirir. Bir çerez üreticisi olarak bu verinin nereye gittiğini incelediğimizde çarpıcı bir gerçekle karşılaşırız:

2. Çerez Mekanizmasını Bozmadan Medyayı Nasıl Engelleriz?

Eğer sayfada JavaScript'i kapatırsanız, Google Analytics ve reklam çerezleri yazılmaz; çerezleriniz kalitesiz olur.

🎯 Hassas Cerrahi Kuralı

HTML'e izin ver + CSS'e izin ver + JavaScript'e izin ver.
Fakat tarayıcının indirmek istediği .png, .jpg, .jpeg, .webp, .gif, .mp4, .webm, .woff, .woff2 dosyalarını ağ seviyesinde anında ABORT (düşür) et!

3. Production-Ready Python Kodu (`media_blocker.py`)

Playwright'ın page.route API'sini kullanarak sayfaların ışık hızında yüklenmesini sağlayan ve trafiği %90 düşüren filtreleme kodu: 

import asyncio
from playwright.async_api import async_playwright, Route, Request

# Engellenecek dosya uzantıları ve kaynak türleri
BLOCKED_RESOURCE_TYPES = {"image", "media", "font"}
BLOCKED_EXTENSIONS = (
    ".png", ".jpg", ".jpeg", ".webp", ".gif", ".svg",
    ".mp4", ".webm", ".avi", ".mp3",
    ".woff", ".woff2", ".ttf", ".eot", ".otf"
)

async def resource_filter_handler(route: Route, request: Request):
    """Gereksiz medya isteklerini ağ seviyesinde düşürür, kotayı korur."""
    req_type = request.resource_type
    url = request.url.lower()

    # 1. Kaynak türü kontrolü
    if req_type in BLOCKED_RESOURCE_TYPES:
        await route.abort()
        return

    # 2. Uzantı kontrolü
    if any(url.endswith(ext) or ext in url.split("?")[0] for ext in BLOCKED_EXTENSIONS):
        await route.abort()
        return

    # 3. İzin verilen istekler (HTML, JS, CSS, XHR, Fetch)
    await route.continue_()

async def run_optimized_worker():
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        context = await browser.new_context()
        page = await context.new_page()

        # Rota filtresini tüm istekler için aktif et:
        await page.route("**/*", resource_filter_handler)

        # Haber sitesini aç:
        print("Sayfa yükleniyor...")
        await page.goto("https://www.hurriyet.com.tr", wait_until="domcontentloaded")

        # Çerezleri kontrol et:
        cookies = await context.cookies()
        print(f"Başarıyla toplanan çerez sayısı: {len(cookies)}")
        
        await browser.close()

if __name__ == "__main__":
    asyncio.run(run_optimized_worker())
