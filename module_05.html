1. Temel Ticari ve Teknik Tanım: Biz Müşteriye Aslında Ne Satıyoruz?

Bu ticaret alanına yeni adım atanların zihnini en çok karıştıran soru şudur: "Biz kullanıcılara tek bir site için ziyaret çerezi mi satacağız, bir çerez seti mi, yoksa profilin tamamını mı?"

Kısa ve net cevap: Piyasada asıl satılan standart ürün, "Tek bir sitenin çerezi" DEĞİL, tek bir sanal insanın gezintisiyle oluşan "BİR PROFİLİN TÜM ÇEREZLERİDİR (Çerez Seti)".

📦 ÇEREZ TİCARETİNDE ÜRÜN ÇEŞİTLERİ VE TESLİMAT YAPISI
[MÜŞTERİNİN İNDİRDİĞİ ZIP PAKETİ (Örn: 1.000 Adet)]: 📦 Siparis_1000_Adet.zip ├── 📄 profil_0001.json ──> (Google, Haber, E-Ticaret... 95 çerez) ├── 📄 profil_0002.json ──> (Farklı IP ile gezilmiş 110 çerez) ├── 📄 profil_0003.json ──> (Farklı geçmişle üretilmiş 120 çerez) ├── ... ├── 📄 profil_1000.json └── 📄 user_agents.txt ──> (Her profilin eşleştiği User-Agent)

Neden "Tek Bir Sitenin Çerezi" Satılmaz ve Çöp Hükmündedir?

Diyelim ki tarayıcıyı yalnızca google.com'a soktunuz ve sadece Google'ın verdiği NID ve AEC çerezlerini kaydedip müşteriye sattınız.

  • Müşteri bu çerezi kendi botuna yükleyip Google'da arama yapmaya kalktığında, Google algoritmaları tarayıcı belleğini inceler:
  • "Bu tarayıcıda hiç gazete çerezi yok, hiç YouTube çerezi yok, hiçbir e-ticaret veya sayaç (GA4) çerezi yok. Yaşayan hiçbir gerçek insan dünyada sadece tek bir siteye girip çıkmaz!"
  • Sonuç: Bot anında "anomali / yapay aktivite" olarak etiketlenir, CAPTCHA patlar veya sıralama tıklaması çöpe atılır. Tek site çerezi izole ve yapay olduğu için değersizdir.

Piyasanın Standart Ürünü: "Profil Çerez Seti" (1 Profil = 1 Dosya)

İşte bu yüzden HitBot gibi endüstriyel çiftlikler gerçek bir insanı simüle eder:

  1. HitBot bir tarayıcı açar, temiz bir IP ile Google'a girer, haber portallarına tıklar, YouTube'da gezinir, Trendyol'a uğrar (20-25 saniye).
  2. Bu gezinme sırasında tarayıcı hafızasında 15 farklı sitenin bıraktığı toplam 80 ila 150 adet çerez birikir.
  3. HitBot bu çerezlerin tamamını tek bir dosyaya mühürler: profil_0001.json.

Forum jargonunda (R10, BHW) buna kısaca "1 Adet Çerez" denir; ancak teknik olarak o dosya 1 sanal insanın tüm dijital geçmişini barındıran tam bir çerez setidir.

Müşteri Bu Dosyayı Kendi Botunda Nasıl Kullanır? ("Kullan-At İnsan Kalkanı")

Müşteri sizden 1.000 adetlik paketi aldığında botunu şöyle çalıştırır:

  • 1. Görev: Bot açılır ➔ profil_0001.json dosyasındaki çerezleri tarayıcıya enjekte eder ➔ Hedef sitedeki görevini (tıklama, arama, veri çekme) 3 gündür internette gezen gerçek bir kullanıcı gibi tamamlar ➔ Tarayıcıyı kapatır.
  • 2. Görev: Sıradaki görevi için profil_0002.json çerezlerini yükler. Böylece her görevi farklı ve güvenilir bir insan kimliğiyle yürütülür.

2. Çerezlerin Dosya Formatları: Neden Birden Fazla Standart Var?

Çerez ticaretinde alıcılara çerez teslim ederken onların hangi yazılımı kullandığını bilmek zorundasınız. Bir cURL kullanıcısına JSON verirseniz botu çalışmaz; bir Playwright kullanıcısına Netscape verirseniz hata alır. Bu nedenle her iki ana formatı ve aralarındaki dönüşümü mükemmel bilmeliyiz.

4. Format 2: Netscape / cURL Formatı (`cookies.txt`)

1990'lardan kalma sekme ile ayrılmış (tab-delimited) klasik formattır. Doğrudan cURL, Wget, Python `http.cookiejar` veya Go/C++ request botları bu formatı tercih eder: 

# Netscape HTTP Cookie File
# http://curl.haxx.se/rfc/cookie_spec.html
# This file was generated by HitBot Farm! Edit at your own risk.

.google.com	TRUE	/	TRUE	1778361600	NID	511=dK8F9j2m_x9L3Qv1...
.google.com	TRUE	/	TRUE	1746825600	AEC	AVYB7cqX4Y9...
#HttpOnly_.google.com	TRUE	/	TRUE	1746825600	SOCS	CAESEwgDEgk2...
NETSCAPE COOKIES.TXT FORMAT
📌 Netscape Dosya Sütunlarının Anlamı (Soldan Sağa)
  1. Domain: Çerezin geçerli olduğu alan adı. (Başında #HttpOnly_ varsa HttpOnly çerezdir).
  2. Flag: Alt alan adlarının bu çereze erişip erişemeyeceği (`TRUE` veya `FALSE`).
  3. Path: Dizin kısıtlaması (Genellikle `/`).
  4. Secure: Sadece HTTPS ile mi taşınacağı (`TRUE` veya `FALSE`).
  5. Expiration: UNIX zaman damgası cinsinden son kullanım tarihi (Epoch timestamp).
  6. Name: Çerezin adı.
  7. Value: Çerezin değeri.

5. Chromium Ham SQLite Depolaması ve Şifreleme Tuzağı

Chromium ve Google Chrome, tüm çerezleri diskte bir SQLite 3 veritabanı dosyasında saklar:

  • Windows Yolu: %LOCALAPPDATA%\Google\Chrome\User Data\Default\Network\Cookies
  • Linux Yolu: ~/.config/google-chrome/Default/Network/Cookies
🚨 Acemilerin Düştüğü DPAPI Tuzağı: Dosyayı Kopyalamak Neden Çalışmaz?

Birçok kişi `Cookies` SQLite dosyasını doğrudan müşteriye gönderip satabileceğini düşünür. Oysa Chrome v80+ ve özellikle v120+ sürümlerinde:

  • Çerezin `value` değeri veritabanında düz metin değil, encrypted_value sütununda şifreli (BLOB) olarak tutulur.
  • Windows'ta bu şifreleme DPAPI (CryptProtectData) ve v127+ ile gelen App-Bound Encryption ile o kullanıcının Windows şifresine kilitlenir!
  • O dosyayı başka bir bilgisayara taşıdığınızda Chrome şifreyi çözemez ve tüm çerezleri anında siler!

Doğru Yöntem: Çerezler asla ham dosya olarak kopyalanmaz. Çalışan Playwright oturumundan bellek seviyesinde (`await context.cookies()`) veya CDP `Network.getCookies` protokolüyle şifresi çözülmüş saf metin olarak çekilir ve JSON olarak mühürlenir.

6. İki Yönlü Format Çevirici (Production Python Kodu)

Çerez çiftliğinizde JSON olarak ürettiğiniz bir çerezi tek satırda Netscape formatına dönüştüren veya tam tersini yapan endüstriyel Python fonksiyonu: 

import json
from typing import List, Dict

def json_to_netscape(cookies: List[Dict]) -> str:
    """JSON çerez listesini standart Netscape cookies.txt formatına çevirir."""
    lines = [
        "# Netscape HTTP Cookie File",
        "# Exported by Industrial Cookie Farm Engine",
        ""
    ]
    for c in cookies:
        domain = c.get("domain", "")
        if c.get("httpOnly", False) and not domain.startswith("#HttpOnly_"):
            domain = f"#HttpOnly_{domain}"
            
        flag = "TRUE" if domain.startswith(".") else "FALSE"
        path = c.get("path", "/")
        secure = "TRUE" if c.get("secure", False) else "FALSE"
        
        # Expiry timestamp dönüştürme
        raw_exp = c.get("expirationDate") or c.get("expires") or 0
        expiry = int(float(raw_exp)) if raw_exp else 0
        
        name = c.get("name", "")
        val = c.get("value", "")
        
        lines.append(f"{domain}\t{flag}\t{path}\t{secure}\t{expiry}\t{name}\t{val}")
        
    return "\n".join(lines)

def netscape_to_json(netscape_text: str) -> List[Dict]:
    """Netscape cookies.txt içeriğini JSON formatına dönüştürür."""
    cookies = []
    for line in netscape_text.splitlines():
        line = line.strip()
        if not line or line.startswith("# ") or line == "#":
            continue
            
        parts = line.split("\t")
        if len(parts) < 7:
            continue
            
        domain_raw, flag, path, secure, expiry, name, val = parts[:7]
        http_only = domain_raw.startswith("#HttpOnly_")
        domain = domain_raw.replace("#HttpOnly_", "")
        
        cookies.append({
            "domain": domain,
            "expirationDate": float(expiry) if expiry.isdigit() else None,
            "hostOnly": flag == "FALSE",
            "httpOnly": http_only,
            "name": name,
            "path": path,
            "secure": secure.upper() == "TRUE",
            "value": val
        })
    return cookies
