Modül 09: Donanım Altyapısı: Oracle Cloud Ampere A1 (ARM64) Gücü

4 OCPU Ampere ARM işlemci, 24 GB RAM Always Free altyapısı, aarch64 mimarisinde Chromium derlemeleri ve Oracle Idle Reclaim politikasını kalıcı olarak aşma yöntemleri.

1. Oracle Cloud Always Free: Dünyanın En Güçlü Ücretsiz Donanımı

Bulut bilişim pazarında AWS, Google Cloud veya Azure gibi devler genellikle 1 çekirdek ve 1 GB RAM'lik minik sunucuları 12 ay için ücretsiz verir. Ancak Oracle Cloud Infrastructure (OCI), piyasada eşi benzeri olmayan bir Always Free (Ömür Boyu Ücretsiz) paket sunmaktadır:

🖥️ ORACLE CLOUD AMPERE A1 ALWAYS FREE ÖZELLİKLERİ
+--------------------------------------------------------------+ | İŞLEMCİ : 4 OCPU Ampere Altra ARM64 (Dedicated 4 vCPU) | | BELLEK : 24 GB LPDDR4x RAM (Takassız devasa önbellek) | | DEPOLAMA : 200 GB NVMe Disk (Yüksek IOPS, hızlı SQLite) | | TRAFİK : Aylık 10 TB Ücretsiz Çıkış Bandwidth'i | | PİYASA FİY : Normal VPS'te ~80$/ay (4.000 TL/ay) | | BİZİM GİDER: 0 TL (ÖMÜR BOYU HER AY ÜCRETSİZ!) | +--------------------------------------------------------------+

2. x86_64 vs. ARM64 (aarch64) Mimarisi ve Chromium

Geleneksel Intel/AMD sunucuları x86 mimarisi kullanırken, Ampere işlemcileri Apple Silicon (M1/M2/M3) gibi ARM64 (aarch64) mimarisine sahiptir.

  • Daha Düşük Isı ve Yüksek Verimlilik: ARM çekirdekleri, web sayfalarının JavaScript motoru (V8) için optimize edilmiştir.
  • Chromium Uyumluluğu: Ubuntu 22.04 veya 24.04 ARM64 üzerine Playwright kurduğunuzda, Playwright resmi Chromium ARM64 binary'sini sorunsuz indirir: 
    # Ubuntu ARM64 üzerinde kurulum:
sudo apt update && sudo apt install -y python3-pip chromium-browser
pip3 install playwright
playwright install chromium
BASH TERMINAL
  • Önemli Fark: Derlenmiş Go binary'leri veya harici araçlar kullanılırken GOARCH=arm64 bayrağıyla derlenmelidir.

3. Oracle "Idle Reclaim" (Sunucu Geri Alma) Politikasını Aşmak

Oracle, Always Free kullanıcılarının makinelerini boşta bırakmasını engellemek için bir kural koymuştur: "Eğer bir sunucunun CPU kullanımı 7 gün boyunca %10'un altındaysa ve bellek kullanımı <%10 ise, sunucu durdurulabilir veya geri alınabilir."

🛡️ Çerez Çiftliği ile Otomatik Dokunulmazlık

Bizim çerez çiftliği sistemimiz 7/24 arka planda headless tarayıcılar çalıştıracağı ve siteleri gezeceği için, CPU kullanımımız doğal olarak %25 ila %45 arasında dalgalanacaktır. Böylece Oracle sunucunuzu sistem metriklerinde "aşırı aktif ve üretken" bir makine olarak görür ve makineniz ömür boyu tamamen güvende kalır, asla geri alınamaz!

4. Ubuntu ARM64 Kernel ve Sistem Optimizasyonları

24 GB RAM'i 40-50 eşzamanlı çerez işçisine (worker) paylaştırırken Linux çekirdeğinin kilitlenmemesi için `sysctl.conf` ve dosya sınırları optimize edilmelidir: 

# /etc/security/limits.conf dosyasına ekleyin (Dosya tanıtıcı limitlerini açın):
* soft nofile 65535
* hard nofile 65535
root soft nofile 65535
root hard nofile 65535

# /etc/sysctl.conf dosyasına ekleyin (Ağ ve bellek ayarları):
vm.swappiness=10
net.core.somaxconn=4096
net.ipv4.tcp_max_syn_backlog=4096
net.ipv4.ip_local_port_range=1024 65535
fs.file-max=2097152

# Ayarları aktif edin:
sudo sysctl -p

5. Kapasite Dağılımı: 24 GB RAM ile Kaç Worker Çalışır?

Bellek tüketimini milimetrik olarak hesaplayalım:

Bileşen Birim RAM Tüketimi Toplam Tüketim (40 Worker)
Ubuntu 24.04 ARM64 OS 350 MB 350 MB
MongoDB Veritabanı 1.5 GB (WiredTiger cache) 1.5 GB
Medya Filtreli Chromium Worker ~180 MB 40 x 180 MB = 7.2 GB
Go TLS Proxy & HTTP/2 Swarm ~80 MB 80 MB
Boşta Kalan Güvenli Bellek - ~14.8 GB (Tamamen Güvenli Rezerv!)

Görüldüğü gibi, 24 GB RAM sayesinde sunucumuz 40 eşzamanlı worker'ı çalıştırırken bile belleğinin sadece üçte birini kullanır; hiçbir bellek şişmesi (OOM killer) veya takılma yaşanmaz.
